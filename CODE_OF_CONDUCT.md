# Code of Conduct

RPA Core should be a practical and respectful place to improve local automation
software.

## Expected Behavior

- Be kind, direct, and specific.
- Assume good intent while still reviewing code carefully.
- Keep disagreement focused on behavior, evidence, and maintainability.
- Respect that users may automate sensitive business processes.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private information, credentials, customer data, or exploit details.
- Repeatedly derailing technical discussions after maintainers ask to refocus.
- Pressuring maintainers for private support outside the documented routes.

## Enforcement

Maintainers may edit or remove comments, close issues, block accounts, or pause a
discussion to protect the project. If you need to report conduct concerns, open a
GitHub issue asking for a private maintainer contact and do not include sensitive
details in the public issue.
